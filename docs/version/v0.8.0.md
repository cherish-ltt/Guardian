# v0.8.0

IP 相关改动的版本：**真实 IP 的查看权限**改成三档、并在 axum 返回前完成打码；
**IP 属地不再入库**，改成由前端按钮按需现查并缓存到 Redis；离线地名库改为随仓库下载到
`backend/data/`、默认即启用。对外可见的变化是日志列表的 `ip` 字段按权限打码、`location` 字段
从接口与导出中移除、新增两个属地查询端点，以及三条新的按钮级权限码。

## 后端

- **真实 IP 查看权限分三档**：新增按钮级权限码 `monitor:ip:view:full`（完整地址）与
  `monitor:ip:view:partial`（保留前两段，IPv6 保留前四个 hextet），两者都不授权时只留首尾段
  （`61.x.x.21` / `2001:x:x:x:x:x:x:7334`）。打码在 axum 返回前完成，库里仍是原始地址；
  内网、回环与公网地址一视同仁。超级管理员默认完整地址，系统管理员（`sys_admin`）默认二级查看，
  其余角色默认无权限，只有超级管理员能改授权。实现见 `src/util/ip_mask.rs`。
- **IP 属地不再入库**：`sys_oper_log` / `sys_login_log` 不再写 `location` 列，
  列表、详情与 CSV 导出也不再返回该字段（历史行的原值保留不动）。
- **新增属地现查端点**：`GET /api/v1/monitor/ip-locations?ip=` 与
  `POST /api/v1/monitor/ip-locations`（整页批量，请求 `{"ips": [...]}`），均要求
  `monitor:ip:view:full`，其余档位返回 403。结果按 `guardian:ip-location:v1:<地址>` 缓存到 Redis，
  条目上限 255 条、有效期 3 小时；Redis 不可用时退回每次现查，不挡住查询。
- **离线地名库默认启用**：不配置 `IP_LOCATION_DB_PATH` / `IP_LOCATION_V6_DB_PATH` 时用
  `data/ip2region_v4.xdb` / `data/ip2region_v6.xdb`（相对 backend 启动目录）；显式写成空白
  仍表示不启用。库文件不入库，新增 `backend/scripts/fetch-ip-database.sh` 一键下载
  （支持 `IP_DB_MIRROR` 镜像前缀），`backend/.gitignore` 排除 `data/*.xdb`。
- **属地解析拆出开关**：`IpLocation::resolve` 增加「本地网段是否单列」参数——日志采集仍把回环记为
  「本机」、私网记为「内网」，属地现查则一律查库。
- **种子数据**：`sys_menu` 新增「真实 IP 查看」目录（ID 203）与两个按钮（2031 / 2032），
  `sys_admin` 默认拿到监控目录、该目录与二级查看按钮。
- 文档：`docs/DEPLOYMENT.md` 的「离线 IP 地名库」章节按现查方案重写；`backend/docs/ADMIN.md`
  补两个端点与三档权限表，并说明 `location` 列不再写入；`backend/README.md`、
  `backend/.env-example` 同步新的默认路径与下载方式。

## 前端

- **来源列改成「查询属地」按钮**：操作日志与登录日志的 `ip` 单元格在拿到属地前显示地址 + 查询按钮，
  点击后现查并展示地名；没有 `monitor:ip:view:full` 时显示「无权查看」，不再发起请求。
- **表头批量查询**：表格工具栏新增「查询整页属地」按钮，一次查当前页去重后的地址，
  已查过的地址不会重复请求；结果按地址缓存在页面内，翻页与切页保留。
- 详情抽屉的「来源」同步改为按钮触发；`useIpLocation` composable 统一管理查询与缓存。

## 升级说明

- `.env` 里显式把 `IP_LOCATION_DB_PATH` 留空的环境不受影响；留空且希望启用属地时，
  先跑 `backend/scripts/fetch-ip-database.sh`，再删掉这两行（或改成新路径）并重启。
- 已在跑的环境需要重启一次，让 `sys_menu` 的三条新记录播种进库；之后到「角色管理」里
  给需要的角色勾选「真实 IP 查看」。
