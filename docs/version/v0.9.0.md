# v0.9.0

本版本修复用户与角色授权、日志 IP 脱敏、菜单路由和代码生成器问题。

## 后端

- 限制非超级管理员重置超级管理员密码，防止账号越权接管。
- 日志导出和登录热力图按真实 IP 查看权限脱敏。
- 限制非超级管理员修改角色的真实 IP 查看权限。
- 限制超级管理员角色的修改，并防止撤销最后一个可用超级管理员。
- 用户列表返回部门、角色和岗位 ID，供编辑时准确回填。
- 拒绝菜单设置为自身、后代或不存在的上级，防止菜单树丢失。
- 用户编辑支持用空字符串清空手机号和邮箱，省略字段仍保留原值。
- 用户新增和编辑时校验所选部门存在且未删除。
- 新增用户时校验实际使用的初始密码长度为 6 至 64 个字符。
- 代码生成器识别 SQLite 实际主键，拒绝不支持的主键结构并修复旧配置。

## 前端

- 修复同名部门、角色或岗位导致编辑用户时关联被误改的问题。
- 修复多级目录下已授权页面无法显示和访问的问题。
- 修复用户编辑清空手机号或邮箱后旧值仍被保留的问题。
- 用户创建、重置和个人改密统一按 Unicode 字符校验密码长度。

## 升级说明

- 启动后自动执行数据库迁移，更新代码生成器的已有列配置；升级前按部署流程备份数据库。
- 代码生成器仅支持 SQLite 单列 `INTEGER` 行号主键，其他主键结构会被拒绝。
