# v0.10.1

修复 v0.10.0 日志时间筛选控件无法直接选择日期时间、四个输入框高低不齐的问题（#32 后续修复，PR #37）。

## 后端

- 无。

## 前端

- 操作日志与登录日志改用可直接选择日期、时、分、秒的日期时间组件，支持清空和取消，保留服务端本地时间及半开区间查询 / 导出契约。
- 修正时间字段说明导致四个筛选控件高低不齐的问题，统一控件高度并将说明独立成行；补充实际点选、对齐及桌面 / 窄屏回归。
- 适配站内浅色 / 深色主题，修正短屏弹层越界及关闭后键盘焦点丢失；浏览器夏令时缺口不再影响选中的服务端本地时间文本。

## 验证

- 生产构建联调通过两类日志实际日期和时分秒点选、秒级边界、10+2 行分页、12 行 CSV、单边界、清空 / 重置、取消、Escape / 焦点、空结果、相等边界 400、闰日和纽约夏令时缺口回归。
- 桌面 1720 / 1440px 四个控件均为 36px 高、上下边缘一致；820px、390×844、320×568 窄屏等宽排列且选择弹层未超出视口，已检查截图。
- 43 项前端单元测试、类型检查 / 构建、lint 和适用提交钩子通过；浅色紧凑、深色常规 / 宽松的点选和键盘焦点回返通过。

## 升级说明与限制

- 前后端版本统一为 v0.10.1，后端仅同步版本号，没有接口、数据库迁移或环境配置变化。
- 新增固定版本 `@vuepic/vue-datepicker@14.0.0` 和 `date-fns@4.4.0`；源码部署需执行 `npm ci` 后重新构建，发行包已包含所需前端代码。
- 时间仍按服务端本地时间解释，包含开始、不包含结束，统计图窗口独立；不做浏览器到服务端的时区换算。历史日志没有偏移信息，夏令时重复时刻的歧义仍存在。
- `npm audit --omit=dev` 仍报告 5 项原有 high 依赖条目（Vue / server-renderer、nanoid、postcss、source-map-js），已核对均为基线原有版本，本次未做整树依赖升级；不据此宣称已完成生产可达性评估。
- UI 实测使用 Chrome 与独立测试数据库，未进行实体手机、Safari / Firefox 或生产部署验收。
