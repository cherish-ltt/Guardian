# v0.10.0

本版本实现 #32：按自定义时间窗口查询和导出操作日志与登录日志。

## 后端

- 操作日志与登录日志的列表、计数和 CSV 支持可选 `startTime` / `endTime` 服务端本地时间半开区间，非法时间与逆序 / 相等边界返回 400；保持权限、IP 脱敏、CSV 防护及 5000 行上限。

## 前端

- 操作日志与登录日志新增开始 / 结束时间输入，查询、分页和导出共用条件，支持单边界、清空与重置；界面明确时间口径和结束边界，不影响统计窗口。
- 修复窄屏工作区被宽表格撑开的问题，避免日志时间输入和查询按钮被裁切。

## 升级说明

- 前后端版本统一为 v0.10.0；本版本没有新增数据库迁移、依赖或环境配置。
- 时间参数是可选项，不传时保持原有行为；格式为 `YYYY-MM-DD HH:MM:SS`，按服务端本地时间解释，包含开始、不含结束，不进行浏览器时区换算。
- CSV 最多导出 5000 行，不是全量归档；统计图仍使用独立窗口。历史时间没有偏移信息，夏令时重复时刻的歧义不在本版本解决。
- 继续遵循 [部署说明](../DEPLOYMENT.md)，升级前备份数据库。
