# v0.6.3

统一前端所有下拉选择框：用户表单里的「岗位」「角色」多选下拉改为与「所属部门」同一种下拉，
浮层置顶不被弹窗裁切并带搜索；其他页面的下拉沿用同一套浮层与外观，搜索框按选项数自动开启。
本次只有前端改动，版本号同步递增到 `0.6.3`。

## 后端

- 无。

## 前端

- **岗位 / 角色多选下拉与部门下拉统一**：`ui/MultiCheck.vue` 改为与 `ui/Select.vue` 同一套实现——
  面板 `Teleport` 到 `body`、层级随所在弹窗（`composables/focus.ts` 的 `floatingLayerFor`）、
  空间不足时向上展开，触发器外观共用 `.select-trigger`，不再被表单弹窗的滚动区裁切。
  交互补齐搜索框、方向键移动、回车勾选、Esc 关闭、Tab 收起，以及 `role="combobox"` / `role="listbox"` 语义；
  仍是多选（点击切换、选中项打勾、触发器上以「、」拼接摘要），后端 `postIds` / `roleIds` 数组契约不变。
- **旧的多选下拉样式删除**：`src/styles/components.css` 里内联绝对定位的 `.multi-check-panel` /
  `.multi-check-option` / `.multi-check-caret` 等规则移除，只保留摘要与占位文字，浮层统一复用 `.select-menu`。
- **搜索框按选项数自动开启**：`filterable` 支持 `true` / `false` / `'auto'` 三态，默认 `'auto'`，
  选项数达到 `src/components/ui/select-shared.ts` 的 `SELECT_SEARCH_THRESHOLD`（8）才显示搜索输入框。
  字典下拉（状态、结果）、角色数据权限、字典标签样式这类短列表不再出现无用的搜索行；
  上级菜单、图标等长列表照旧带搜索。需要强制开启或关闭时显式传 `filterable`。
- **浮层定位抽成共用模块**：`src/composables/popover.ts` 提供 `placePopover` 与 `trackPopover`，
  由 `Select` 与 `MultiCheck` 共用；左右位置夹在视口内（此前贴右边缘会溢出），
  面板自身滚动不再触发重新摆位，滚动与窗口尺寸变化仍会跟随。
