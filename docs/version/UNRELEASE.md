## 前端

- 用户新建和重置弹窗增加默认关闭的改密开关；登录与刷新先核实身份，待改密账号进入独立页面，无需菜单权限；成功后统一重新登录，并隔离重复提交、跨标签页及迟到响应。
- 同一会话重复收到待改密响应时保留正在提交的改密结果，成功后正确清除会话并跳转登录。
- 生成器新增「同步结构」弹窗，展示新增 / 删除以及类型、可空性、主键、顺序的前后差异；支持取消与确认，失败后重新预览，防止旧会话异步响应更新页面。
- 同步结构弹窗按打开时的 token 和会话版本绑定预览与确认；会话变化后停止提交及回调，卸载后忽略迟到响应，避免旧成功提示或列表刷新影响当前页面。
- 代码生成页面增加「移除配置」确认，明确自定义配置永久丢失；成功刷新列表及导入候选，失败保留原行。确认、删除和刷新绑定原会话，退出、跨标签页换号或首次要求改密时取消待决确认；共用列表与导出忽略换号或页面卸载后的迟到结果（#42）。
- 跨标签页更换账号时先卸载旧业务页，完成新身份和菜单校验后再挂载；即使落点路径相同也重建页面，避免旧删除或导出的忙碌状态留在新会话。
