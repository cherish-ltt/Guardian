# v0.4.0

本次发布让登录日志与操作日志的 `location` 列对 IPv6 来源也能给出地名，并统一了前后端版本号。

## 后端

- **地名解析支持 IPv6**：`IpLocation` 由单个查询器改为 IPv4 / IPv6 各一个，按来源 IP 的协议
  分别查询离线库。此前 IPv6 公网来源只能记「外网」，现在与 IPv4 一样写入库里的地名。
- **新增 `IP_LOCATION_V6_DB_PATH`**：与既有的 `IP_LOCATION_DB_PATH` 并列、互相独立。只配其中一个时
  另一个协议的来源仍按本地网段与「外网」判定，不会回落到另一个库。
- **启动即暴露配错的库**：加载库时用一条本机地址探测一次，库头记录的 IP 版本与配置的变量不符时
  直接启动失败，不会静默退回「外网」。文件不存在、不是合法 xdb 的行为保持不变。
- **启动配置日志**：`ip_location` 组新增 `ip_location_v6_db_path`，仍按原有约定输出实际路径或
  `(not set)`；`tests/logging_interval_tests.rs` 的字段覆盖断言自动纳入新字段。
- **测试**：`config_tests.rs` 的路径用例同时覆盖两个变量（含空白视为未配置），
  `ip_location.rs` 的失败用例分别覆盖 v4 与 v6 库路径。
- **文档**：`docs/DEPLOYMENT.md`、`.env-example`、后端 README、`docs/LOGGING.md` 与 vendor 升级步骤
  同步 IPv6 库的下载、配置与回退行为。

## 前端

- 无。版本号仍随本次发布同步递增到 `0.4.0`，代码无改动。
