# v0.5.1

修复 `v0.5.0` 前端产物里的一个回归缺陷。**只改了前端，后端无变动**，但按仓库约定两端版本号同步递增。
使用 `v0.5.0` 前端产物的部署应升级到本版本。

## 前端

- **修复列表页底部漏出表单**：`FormDialog.vue`、`SearchForm.vue`、`NoAccess.vue` 三处的
  `import` 被误放到 `<script setup>` 之外。SFC 编译器对此不报错，但 import 不在 script 块内
  就不生效，`Modal` / `Button` / `EmptyState` 都没有注册，具体表现为：
  - 所有列表页（用户、角色、岗位、部门、菜单、字典、参数、登录日志、操作日志等）底部
    多出整块未受控的表单，页面上关不掉；
  - 各列表页查询区的「查询」「重置」按钮点击无效；
  - 无权限页（`/no-access`）内容空白。

  三处 import 移回 `<script setup>` 内即恢复。类型检查与 lint 对这类错误不敏感，
  两者在 `v0.5.0` 都是通过的，因此新增了结构守卫测试。

- **新增 SFC 结构守卫测试**：`src/components/__tests__/sfc-structure.test.ts` 扫描
  `src` 下全部 `.vue`，断言 `import` / `export` 都出现在 `<script>` 块内，并断言每个 SFC
  都有 script 块。已反向验证：把任意一处 import 移出 script 块时该测试失败。

## 后端

- 无。版本号随本次发布同步递增到 `0.5.1`，代码无改动。
