# v0.8.1

属地查询的修复版本：未配置地名库时，本机与内网地址不再被算成「外网」。
对外表现是日志里的 `127.0.0.1` 现在显示「本机」、RFC1918 私网与 IPv6 ULA 显示「内网」，
这两档不再尝试查库。无配置变更，无需改动 `.env`。

## 后端

- **属地现查不再把本机与内网算成「外网」**：`IpLocation` 新增 `local_label` 统一判定回环与内网，
  `IpLocationService` 先用它给出「本机」「内网」再决定是否查库。此前属地现查一律查库，
  未配置地名库时查不到记录就退回「外网」。
- 判定范围：IPv4 回环（`127.0.0.0/8`）、IPv6 回环（`::1`）为「本机」；RFC1918 私网、
  链路本地（`169.254.0.0/16`、`fe80::/10`）与 IPv6 ULA（`fc00::/7`）为「内网」。
- **属地缓存键前缀升到 `guardian:ip-location:v2`**：`v1` 里被记成「外网」的本地网段不再命中；
  本地网段不查库，也不占缓存条目。

## 升级说明

- 无配置变更，`.env` 不需要改动。
- 缓存键前缀已经变化，旧版本的 `guardian:ip-location:v1:*` 条目会自然过期，不需要手动清理。
